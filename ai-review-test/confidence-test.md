# Export a report from a saved search [export-report]

This throwaway page exists only to test how an automated docs review behaves. It contains a few deliberate problems.

## Before you export

Check that you have a saved search. The export limit is 50,000 rows starting in 9.9, and larger exports run in the background.

### Steps

The following three steps export a report.

1. Open the saved search.
2. Select **Share**.
3. Select **Export as CSV**.
4. Wait for the download to finish.

As example, you can schedule the same export to run every week. This will makes it easier to track changes.

For more information, refer to [Export a report from a saved search](/ai-review-test/confidence-test.md).
