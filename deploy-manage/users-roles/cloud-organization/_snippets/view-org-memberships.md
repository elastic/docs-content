You can view the organizations that your users are members of from the **Members** page. This page shows which organizations each member of your current organization belongs to.

To view the organizations:

1. Log in to the [{{ecloud}} Console](https://cloud.elastic.co?page=docs&placement=docs-body).
2. From a deployment or project on the home page, select **Manage**.
3. From the navigation menu, select **Organization** > **Members**.
4. Click the name of the user whose organization memberships you want to view.
