* **Cloud ID:** If an {{ech}} deployment is protected by an AWS PrivateLink VPC filter, you can't use Cloud ID to connect clients like Beats or Logstash to the deployment. The Cloud ID encodes the public {{es}} endpoint, which is not available after the filter is associated. [Find the private {{es}} URL](/deploy-manage/security/private-connectivity-aws.md#ec-access-the-deployment-over-private-link), then connect using that URL and an API key. For examples, refer to the [Beats](beats://reference/metricbeat/configure-cloud-id.md) and [Logstash](logstash://reference/connecting-to-cloud.md) documentation.
