* **Cloud ID:** If an {{ech}} deployment is protected by an AWS PrivateLink VPC filter, you can't use Cloud ID to connect clients like Beats or Logstash to the deployment. The Cloud ID encodes the public {{es}} endpoint, which is not available after the filter is associated. To connect with the private {{es}} endpoint and an API key, refer to [Configure the output for {{ech}}](beats://reference/metricbeat/configure-cloud-id.md) and [Sending data to {{ech}}](logstash://reference/connecting-to-cloud.md).
