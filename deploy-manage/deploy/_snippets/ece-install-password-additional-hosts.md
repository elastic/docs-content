{applies_to}`ece: ga 4.3+` If your installation has an [install password](/deploy-manage/security/secure-your-elastic-cloud-enterprise-installation/configure-ece-install-password.md), include `--install-password 'PASSWORD'` in the installation command on every additional host, or set the `INSTALL_PASSWORD` environment variable before you run the script.
