A bundle is a ZIP file whose entire content is extracted to the `/app/config` directory of every {{es}} node. The directory structure inside the ZIP file determines where the files land: folders such as `truststore`, `saml`, and `ingest-geoip` keep their names, so a bundle that contains `truststore/keystore.ks` makes the keystore available at `/app/config/truststore/keystore.ks`. Use that full path when you reference the file in your {{es}} settings.
