Before you start, make sure you have data [indexed into {{es}}](/manage-data/ingest.md) or [install sample data](/manage-data/ingest/sample-data.md). {{esql}} queries the indices named in the query directly, so you do not need a data view. The columns returned by the query become available as chart dimensions. Refer to [Visualizations using {{esql}} queries](/explore-analyze/visualize/esorql.md) to learn how to open the editor, shape the query result for a visualization, and save the visualization.
