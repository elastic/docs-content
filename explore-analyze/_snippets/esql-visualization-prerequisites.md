Before you start, make sure you have data [indexed into {{es}}](/manage-data/ingest.md) or [install sample data](/manage-data/ingest/sample-data.md). {{esql}} queries the indices named in the query directly, so you do not need a data view. Refer to [Lens visualizations using {{esql}} queries](/explore-analyze/visualize/esorql.md) to learn how to open the editor, run queries, and save the visualization.
