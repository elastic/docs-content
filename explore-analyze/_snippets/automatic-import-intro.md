% Shared intro body for Automatic Import: canonical page and solution stub pages. 

Automatic Import builds a custom integration for data sources that don't have a prebuilt Elastic integration, such as in-house applications. You upload a sample of your data, and a large language model (LLM) generates an ingest pipeline that parses the data and maps it to the [Elastic Common Schema (ECS)](ecs://reference/index.md). You can then use the data in dashboards, search, alerts, and machine learning features, like data from any other integration.
