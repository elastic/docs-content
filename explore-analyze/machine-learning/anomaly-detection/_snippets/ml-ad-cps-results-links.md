:::{note}
:applies_to: {"stack": "unavailable", "serverless": "preview"}
The job's project scope is not passed to **Discover** or any other links opened from the results. When you open the link, set the [{{cps-init}} scope selector](/explore-analyze/cross-project-search/cross-project-search-manage-scope.md#cps-in-kibana) to match the job. If you open a dashboard that [stores a {{cps-init}} scope](/explore-analyze/dashboards/create-dashboard.md), the selector restores that dashboard's saved scope, not the job's.
:::
