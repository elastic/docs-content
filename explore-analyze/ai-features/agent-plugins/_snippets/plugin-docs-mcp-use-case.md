The plugin registers the [Elastic Docs MCP server](/get-started/machine-readable-docs.md#docs-mcp-server), which lets the agent search and retrieve Elastic documentation as part of any conversation.
The agent can look up configuration options, API references, and feature guides without leaving {{plugin-host}}.

::::{note}
The Elastic Docs MCP server only gives the agent access to Elastic documentation, not to your data.
To let the agent work with your data, install and configure the [Elastic CLI](cli://index.md).
::::
