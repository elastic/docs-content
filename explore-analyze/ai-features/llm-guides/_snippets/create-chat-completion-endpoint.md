Create an {{infer}} endpoint so that {{kib}} can use models from {{model-provider}}. AI features in {{kib}} can use only endpoints with the `chat_completion` task type. For more information about adding endpoints, refer to [External {{infer}}](/explore-analyze/elastic-inference/external.md#add-inference-endpoints).

1. Go to the **External {{infer}}** page by using the navigation menu or the [global search field](/explore-analyze/find-and-organize/find-apps-and-objects.md).
2. Select **Add endpoint**.
3. Select **{{inference-service}}** as the service.
