# Amazon S3 destination

An **Amazon S3** destination writes data from a stream to an S3 bucket you own, as newline-delimited JSON (NDJSON). Use it to keep the complete record on infrastructure you control while a filtered subset goes to {{es}}, to satisfy a retention or residency requirement, or to archive data you rarely query. A copy rule is the usual way to send data to it, so that the full stream goes to the bucket and a filtered rule goes to an {{es}} destination. You bring the bucket and the credentials. Streams encrypts the access key pair when you save it and writes the objects for you.

:::{include} /manage-data/ingest/streams/_snippets/private-preview-note.md
:::

In the create dialog, this type is the **External storage** choice. Once the destination exists, the Streams Map and the **Destinations** tab show its type as **Amazon S3**.

## Before you begin [streams-s3-destination-prereqs]

To create an Amazon S3 destination, you need:

* The **Admin** role. Refer to [Privileges and API keys](../security.md#streams-security-view-edit).
* An S3 bucket, its AWS region, and optionally a key prefix for the objects Streams writes.
* An AWS access key ID and secret access key for an IAM identity that can write to that bucket and prefix. `s3:PutObject` on the prefix is enough. Streams can't narrow the credential, so create one for this destination alone rather than reusing a broader key.

## Create the destination [streams-s3-destination-create]

You create the destination on the Streams Map, and it exists as soon as you save the dialog:

1. Find **Streams** in the navigation menu or use the [global search field](/explore-analyze/find-and-organize/find-apps-and-objects.md), then select the **Map** tab.
1. Select **Destination** in the toolbar at the bottom of the Map.
1. Under **Where will this destination's data live?**, select **External storage**.
1. Leave **Provider** as **Amazon S3**, the only provider offered, and enter the **Region** of the bucket, the **Bucket** name, and optionally a **Prefix**. Time partitions and object names are appended to the prefix.
1. Enter the **Access key ID** and **Secret access key**.
1. Enter a **Destination name** and, optionally, a **Description**. The name must be unique among your destinations and can't be changed later.
1. Select **Create destination**.

The destination appears on the Map with the bucket name under its name. Connect a source, pipeline, or router to it and select **Save changes**. The node shows no state or statistics, so check that objects arrive by listing the bucket.

Streams encrypts the access key pair when you save it and never shows it again. The destination's details show the **Bucket**, **Region**, and **Prefix**, and the **Access key ID** and **Secret access key** as **Configured**. Destinations can't be edited, so to rotate the keys, create a new destination with the new pair, reconnect the routing rules to it, and delete the old one.

## What's written to the bucket [streams-s3-destination-bucket]

The destination accepts logs, metrics, and traces, and documents from a Managed _bulk source. Streams writes each record as one JSON line, after any processing in the pipelines upstream of the destination, and groups records into objects under your prefix by time. NDJSON is the only format, and there's no format setting.

NDJSON objects can be read in place with [{{esql}} Data Federation](elasticsearch://reference/query-languages/esql/esql-data-federation.md) from a deployment where that feature is available, so a record you chose not to index stays reachable with the same query language you use for {{es}}.

## Delivery to S3 [streams-s3-destination-delivery]

A record the destination can't write, because the credential is rejected, the bucket or region is wrong, or the identity lacks permission on the prefix, is dropped, and the drop isn't reported on the Streams Map. Keep your existing archive path running next to the S3 destination until you've confirmed objects arrive. Refer to [When a destination can't store data](../destinations.md#streams-destinations-cant-store).
