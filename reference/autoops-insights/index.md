# AutoOps insights

AutoOps monitors hundreds of metrics on your deployment and raises an insight when it detects a condition that affects performance, stability, or resource efficiency. Each insight identifies the root cause, explains the impact, and surfaces targeted recommendations so you can act quickly.

Browse the insights by the component they monitor:

- [AutoOps insights for {{es}}](autoops-insights://elasticsearch/index.md): Insights about the health, performance, and configuration of your {{es}} clusters.
