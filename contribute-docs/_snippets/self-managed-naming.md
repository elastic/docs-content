:::{note}
*Self-managed environments* can include directly managed clusters and the ECE and ECK platforms that you operate yourself. The **Self-managed** deployment type and the `deployment.self` key refer only to clusters managed directly, without ECE or ECK orchestration. For deployment-specific instructions and applicability tags, identify each deployment type explicitly. Refer to [Self-managed platforms and deployment types](/contribute-docs/how-to/deployment-types/about.md#self-managed-platforms-and-deployment-types).
:::
