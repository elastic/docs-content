# Set up {{elastic-sec}}

Set up covers the one-time work to deploy {{elastic-sec}} protections in your environment. After setup, you can find the ongoing work for each feature in [Manage](/solutions/security/manage.md).

- [Configure endpoint protection with {{elastic-defend}}](/solutions/security/configure-elastic-defend.md): Deploy {{elastic-defend}} to protect hosts from malware, ransomware, and malicious behavior.
- [Set up cloud security](/solutions/security/set-up/set-up-cloud-security.md): Connect your cloud accounts and Kubernetes clusters to posture management, asset discovery, and vulnerability scanning.
- {applies_to}`stack: beta 9.3` {applies_to}`serverless: beta` [Get started with Defend for Containers for Kubernetes](/solutions/security/cloud/d4c/get-started-with-d4c.md): Deploy runtime protection for Kubernetes workloads. To protect Linux VMs, install {{elastic-defend}}.
- [Entity analytics requirements](/solutions/security/advanced-entity-analytics/entity-analytics-requirements.md): Check the subscription, privileges, and limitations for entity analytics.
- [Machine learning job and rule requirements](/solutions/security/advanced-entity-analytics/machine-learning-job-rule-requirements.md): Check the subscription, roles, and {{ml}} nodes you need to run {{ml}} jobs and rules.
