# Set up {{elastic-sec}} [security-set-up]

After you [ingest data](/solutions/security/ingest-data.md), set up the {{elastic-sec}} capabilities you plan to use. This section collects the one-time setup tasks for each capability: deploying endpoint protection, connecting cloud security integrations, and meeting the requirements for entity analytics.

Before you start, make sure your deployment meets the general [{{elastic-sec}} requirements](/solutions/security/get-started/elastic-security-requirements.md).

## Where to start [set-up-where-to-start]

| Your goal | Start here |
|---|---|
| Protect hosts against malware, ransomware, and behavioral threats | [Configure endpoint protection with {{elastic-defend}}](/solutions/security/configure-elastic-defend.md) |
| Evaluate your cloud and Kubernetes configuration, inventory cloud assets, or scan cloud workloads for vulnerabilities | [Set up cloud security](/solutions/security/cloud/set-up-cloud-security.md) |
| Use entity risk scoring, asset criticality, or the entity store | [Entity analytics requirements](/solutions/security/advanced-entity-analytics/entity-analytics-requirements.md) |
