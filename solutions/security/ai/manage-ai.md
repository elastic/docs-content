# Manage AI

Manage the knowledge and data that {{elastic-sec}} AI features use.

- [AI Assistant Knowledge Base](/solutions/security/ai/ai-assistant-knowledge-base.md): Add documents and indices that AI Assistant can use as context, including data from third-party apps that you ingest with content connectors.
- [Anonymization](/solutions/security/ai/ai-assistant.md#ai-assistant-anonymization): Set which alert fields AI features can access, and which values they anonymize before sending them to an LLM.
