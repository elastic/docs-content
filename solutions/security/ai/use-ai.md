# Use AI in {{elastic-sec}}

Use AI to triage alerts, investigate threats, and write queries. To set these features up first, refer to [Set up AI features](/solutions/security/ai/set-up-ai-features.md).

- {applies_to}`stack: ga 9.4+, preview 9.3` {applies_to}`serverless: ga` [{{agent-builder}} for {{elastic-sec}}](/solutions/security/ai/agent-builder/agent-builder.md): Chat with the Elastic AI Agent, which uses Security skills to investigate alerts, hunt for threats, and create detection rules.
- [Attack Discovery](/solutions/security/ai/attack-discovery/index.md): Group related alerts into attack narratives so you can prioritize investigation.
- [AI use cases](/solutions/security/ai/use-cases.md): Walk through example workflows for alert triage, threat investigation, and {{esql}} queries.
- [AI Assistant for Security](/solutions/security/ai/ai-assistant.md): Chat with AI Assistant about alerts, incidents, and queries. Starting in 9.4, {{agent-builder}} is the default chat experience.
