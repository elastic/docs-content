# Manage {{elastic-sec}} [security-manage]

After you [set up](/solutions/security/set-up.md) {{elastic-sec}}, use this section for the administration tasks you return to regularly: keeping endpoint protection tuned and healthy, and configuring the workspace your analysts use.

## Where to start [manage-where-to-start]

| Your goal | Start here |
|---|---|
| Monitor endpoints, tune policies, and create exceptions for {{elastic-defend}} | [Manage {{elastic-defend}}](/solutions/security/manage-elastic-defend.md) |
| Restore or retrieve a file that {{elastic-defend}} quarantined | [Manage quarantined files](/solutions/security/manage-elastic-defend/manage-quarantined-files.md) |
| Keep an air-gapped artifact server current | [Manually copy artifact updates](/solutions/security/manage-elastic-defend/manually-copy-artifact-updates.md) |
| Organize security operations into spaces, control which data appears, or add computed fields | [Workspace settings](/solutions/security/workspace-settings.md) |
