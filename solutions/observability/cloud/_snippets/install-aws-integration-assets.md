1. In {{kib}}, search for `AWS` in the [global search field](/explore-analyze/find-and-organize/find-apps-and-objects.md).
2. Select the result named **AWS**, not a result for a single service such as **AWS CloudTrail**.

    The integration's **Overview** page opens.

3. Select the **Settings** tab and click **Install AWS**. In the confirmation dialog, click **Install AWS**.

    If the **Settings** tab shows the AWS integration as installed, the assets are already in place.
