# Set up {{es}} for search [set-up-elasticsearch-for-search]

If you're building search on {{es}}, start here. These pages take you from selecting where to run {{es}} to sending your first request from code.

1. [](/solutions/search/set-up/get-elasticsearch-running-for-search.md): Compare fully managed and self-managed options, and select the one that fits how much infrastructure you want to run.
2. [](/solutions/search/set-up/api-key-and-endpoints.md): Find your endpoint URL and create an API key.
3. [](/solutions/search/set-up/connect-with-an-sdk.md): Connect programmatically, install a language client, and send a request from code. If you don't want to connect programmatically, you can also get started with {{es}} in the {{kib}} [{{dev-tools-app}} Console](/explore-analyze/query-filter/tools/console.md).
