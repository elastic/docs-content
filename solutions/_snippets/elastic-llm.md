{{ech}} deployments and {{serverless-full}} projects include a preconfigured LLM connector that's enabled by default and ready to use.

Using the preconfigured LLM enables you to use features such as Agent Builder and AI Assistant without having an account with an LLM provider or setting up an LLM connector. 

(Search Playground also uses the preconfigured LLM. {applies_to}`stack: preview =9.0, beta 9.1-9.3, deprecated 9.4-9.5, removed 9.6+` {applies_to}`serverless: unavailable`)

The LLM is hosted as a service and will incur additional costs.
For more details, refer to the [pricing page](https://www.elastic.co/pricing).
