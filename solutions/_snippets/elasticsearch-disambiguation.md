{{es}} is the [open source](https://github.com/elastic/elasticsearch) search database for AI. It is the search and analytics engine, data store, and vector database at the core of the Elastic platform, and it is part of every [Elastic deployment type](/deploy-manage/deploy.md). To learn more, refer to [{{es}} in the {{stack}}](/get-started/the-stack.md#stack-components-elasticsearch).

Depending on the context, "{{es}}" can also refer to the following:

- A [project type](/deploy-manage/deploy/elastic-cloud/create-serverless-project.md) on {{serverless-full}} that is designed for general-purpose search use cases.
- A [solution](/solutions/index.md) in other Elastic deployment types. Each solution has a [solution view](/reference/glossary/index.md#glossary-solution-view) that controls the navigation and menus that users see in {{kib}}.
- A cluster that you install and manage yourself. The {{es}} docs call this a [self-managed](/deploy-manage/deploy/self-managed.md) deployment.

The Elastic platform is the whole of what Elastic offers. It includes {{es}} and other foundational products, such as {{kib}}, that the Elastic solutions run on.
